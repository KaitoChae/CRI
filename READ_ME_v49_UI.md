# CRI website v49 — consistent publication columns and readable text

- Desktop: all publication rows (with or without graphical abstracts) use the same grid, aligned title, journal, and metrics columns.
- Tablet: article titles share one column, with journal and badges placed underneath without overlap.
- Mobile: rows stack in a single column.
- Small/supporting text has been enlarged moderately across the website; authors, metrics, QS labels, and the publication search are easier to read.
- Scopus/WoS verification, publication syncing, JIF/SJR/Q data, named-author highlighting, languages, and all other existing features are unchanged.
- Update only `assets/site.css` and the `index.html` cache-busting version compared with v48.
- To deploy: upload **the contents of the `CRI` folder** to the GitHub Pages repository root or its configured publishing directory.
